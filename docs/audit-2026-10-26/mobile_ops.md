# Capitol Receipts: Mobile, Privacy and Operations Audit Register

Audit date: 2026-10-26. This was a read-only audit. Nothing was built, signed, pushed or deployed.

Scope:
- iOS shell (`ios-app/`)
- Android status
- Privacy and the data lifecycle
- Deployment, operations and maintainability

Evidence comes from repo files (path:line), read-only Supabase SQL through the MCP (information_schema, pg_constraint, pg_policies, row counts only), `gh` CLI output and a few single curl requests. No iOS build was attempted because no Mac or Xcode was available, so every on-device behaviour is marked Not verified.

Owner key:
- **Austin**: account holder for Apple, Google, Supabase, Vercel and Stripe (Squared Away Labs LLC)
- **Dev**: whoever changes the code

## External requirements checked (October 2026)

**Apple SDK and Xcode.** Since 2026-04-28, uploads to App Store Connect must be built with Xcode 26 or later and the iOS 26 SDK. `ios-app/README.md` still says "Xcode 16 or later", which is stale.
- [Capawesome: Xcode 26 requirement](https://capawesome.io/blog/xcode-26-requirement-for-capacitor-apps/)
- [Apple: upcoming requirements](https://developer-mdn.apple.com/news/upcoming-requirements/)
- [Expo: minimum SDK 26](https://expo.dev/blog/app-store-connect-minimum-sdk-26)

**Google Play target API.** From 2026-08-31, new apps and updates must target Android 16 (API 36). An extension to 2026-11-01 can be requested.
- [Android developers: target SDK](https://developer.android.com/google/play/requirements/target-sdk)
- [Play Console help](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en-419)

**Capacitor privacy manifest.** Capacitor's docs say an app only needs its own `PrivacyInfo.xcprivacy` if App Store Connect flags it, and give UserDefaults (`CA92.1`) as the example entry.
- [Capacitor: privacy manifest](https://capacitorjs.com/docs/ios/privacy-manifest)

**App Store guidelines.** The 4.2, 4.8, 3.1.1, 3.1.3(b) and 5.1.1(v) guideline points below come from Apple's published App Review Guidelines. The guideline page itself was not fetched in this run.
